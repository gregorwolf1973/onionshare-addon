# OnionShare HA Add-on Repository

A Home Assistant add-on that brings [OnionShare](https://onionshare.org/) to HA OS:
share files, receive uploads, host websites, and chat anonymously over Tor.

## Add this repository

1. In Home Assistant: **Settings → Add-ons → Add-on Store → ⋮ → Repositories**
2. Paste: `https://github.com/gregorwolf1973/onionshare-addon`
3. Install the **OnionShare** add-on that appears.

See [`onionshare/README.md`](onionshare/README.md) for full docs.
